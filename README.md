# Road Accident Data Analysis

## 📊 Project Overview

An interactive data analysis project focused on identifying road accident patterns across Indian states.

The project analyzes accident-related data to understand accident severity, vehicle categories, state-wise patterns, and other key accident metrics.

## 📈 Dashboard Analysis

- State-wise accident analysis
- Accident severity analysis
- Vehicle type analysis
- Category-wise accident patterns
- Comparison of accident-related metrics
- Interactive filtering and visual exploration

## 🗂️ Dataset

- 10,000+ accident records
- Data covering Indian states
- Multiple accident-related categories and attributes

## 🛠️ Tools & Technologies

- Data Analysis
- Data Visualization
- Interactive Dashboard Design
